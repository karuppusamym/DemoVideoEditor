# Code of Conduct

Everyone is welcome to use and contribute to ClipEditor. This code applies to GitHub issues, pull requests, reviews, and other project spaces.

- Treat other people with respect, including when you disagree. Keep feedback specific and focused on the work.
- Welcome contributors of all backgrounds and experience levels.
- Harassment, discrimination, personal attacks, unwanted sexual attention, and publishing someone else's private information without permission are unacceptable.

On GitHub, use **Report content** to report abusive content privately to GitHub. If a private message to a project maintainer is appropriate, describe the incident, include links if available, and share only the personal details needed to address the report.

Maintainers may edit or remove content, moderate conversations, or limit participation to protect the community. They will handle reports discreetly and share information as needed to respond.
